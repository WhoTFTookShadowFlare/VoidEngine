# VoidEngine

A game engine made specifically for desktop platforms.

## Build instructions
### Linux
Install:
- glm
- SDL3
- glbinding
- cpython (3.13/1.14)
- premake5 (5.x)

[bash]
# premake5 gmake
# make

The output can be found in *bin/[config]/DPD*

### Windows
**The only way I have managed to build things on Windows is using [MSYS2](https://www.msys2.org/)**

####Build dependencies
- glm
- SDL3
- glbinding
- cpython (3.13/3.14)

####Build system
- premake (5.x)
- gnu make

[base]
# premake5 gmake
# make

The output can be found in *bin/[config]/DPD.exe"
